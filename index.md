Explanation of CSS Selectors


Universal Selector (*) — Applies box-sizing: border-box to all elements.

Element Selector (body, p) — Selects elements by their HTML tag names.

Class Selector (.card) — Styles all sections having the class card.

ID Selector (#intro) — Styles the section with the unique ID intro.

Grouping Selector (h1, h2, p) — Applies the same margin rule to headings and paragraphs.

Cascade and Specificity (p and .highlight) — The paragraph element rule sets the text to green, but the class selector .highlight sets it to red. Since a class selector has higher specificity than an element selector, the highlighted paragraph appears red.
